# Development Process

## Chosen Model: Scrum

The Smart Inventory System is developed using **Scrum**, adapted for a solo developer.
I act as Product Owner, Scrum Master, and Development Team.

## Project Board

All work is tracked on the GitHub Projects board:
https://github.com/users/Talalsrx/projects/1

Columns: **Backlog → In Progress → Done**

## Product Backlog

Work items are written as user stories from the shop owner's perspective
("As a shop owner, I want... so that...") and ordered by priority.
Core stock management comes first; alerts and the AI restock analyzer come later
because they depend on accurate product and sales data.

## Sprints

- **Length:** 2 weeks
- **Sprint 1 (Sep 27 – Oct 10)**
  - **Goal:** A shop owner can add, edit, and delete products, and stock updates when a sale is recorded.
  - **Stories:** #9, #10, #11, #12

## Definition of Done

A story moves to **Done** only when the feature works and has been tested.
Testing happens inside each story, not as a separate phase at the end.

## Sprint Events (solo adaptation)

- **Sprint Planning:** choose stories from the Backlog at the start of each sprint
- **Daily check-in:** short personal review of progress on the board
- **Sprint Review & Retrospective:** at the end of each sprint, review what was finished and adjust the backlog
